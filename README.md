# Nebras Ahmad — Civil Engineering Portfolio

A modern, responsive personal portfolio website designed for **Nebras Ahmad**, a Civil Engineer specializing in structural engineering, construction, and technical design.

The project combines **engineering aesthetics, architectural minimalism, and modern web technologies** to create a professional digital presence that showcases engineering expertise, selected projects, technical skills, and professional experience.

## ✦ Overview

The website is designed around a dark engineering-inspired visual identity, using technical grids, architectural imagery, precise typography, subtle animations, and an amber accent color.

The goal is to present engineering work in a way that feels **professional, technical, modern, and visually distinctive**, rather than following the traditional style of personal portfolio websites.

## ✦ Main Features

- Modern engineering-inspired UI/UX
- Fully responsive design for desktop, tablet, and mobile
- Animated hero section
- Personal profile and About section
- Projects showcase
- Dedicated Projects page
- Project filtering by engineering discipline
- Revit and ETABS project categories
- Individual project detail pages
- Technical project information and documentation
- Experience section
- Engineering expertise section
- Responsive mobile navigation
- Animated loading and Suspense states
- Architectural and blueprint-inspired visual elements
- Smooth Framer Motion animations
- Optimized images using Next.js Image
- Dark architectural design system

## ✦ Project Categories

The Projects section is organized around different engineering workflows, including:

### Revit

Projects focused on BIM modeling, architectural/structural modeling, technical documentation, and digital construction workflows.

### ETABS

Structural engineering projects involving structural modeling, analysis, load applications, design, and structural system development using ETABS.

The Projects page allows users to filter projects by category and navigate to dedicated project detail pages.

## ✦ Responsive Experience

The website is designed to provide a consistent experience across:

- Desktop
- Laptop
- Tablet
- Mobile

The navigation automatically transforms into a mobile menu, while project grids, typography, images, and spacing adapt to smaller screens.

## ✦ Animation

Animations are intentionally subtle and functional.

Framer Motion is used for:

- Hero entrance animations
- Project card reveals
- Page transitions
- Mobile navigation
- Image transitions
- Loading states
- Suspense fallbacks

The animation system is designed to support the engineering aesthetic without distracting from the content.
